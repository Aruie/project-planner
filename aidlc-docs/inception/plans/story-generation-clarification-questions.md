# User Story Planning Clarification Questions

## 배경
Question 5 답변으로 기존 RFP 처리 흐름이 변경됩니다. 사용자는 프로젝트 진입과 별개인 **채팅형 AI 작업공간**에서 자료를 대화식으로 입력·수정하고, AI가 요구사항정의서 내용을 갱신하며, 검토 전까지는 정식 저장하지 않기를 원합니다.

현재 도메인 모델은 `프로젝트 → 문서 → Draft/확정 버전` 구조이므로, 검토가 끝난 AI 작업 결과를 어느 위치에 저장할지 확정해야 합니다.

## Question 1: 검토 승인 뒤 저장 대상
AI 작업공간에서 요구사항정의서 내용을 검토·승인한 뒤, 결과를 어떻게 처리할까요?

A) 승인 시점에 관리자가 **대상 프로젝트를 선택**하고, 그 프로젝트에 새 요구사항정의서 **Draft 문서**로 저장한다. 이후 일반 Draft 편집·버전 확정 흐름을 따른다. (제안)

B) AI 작업공간은 프로젝트와 무관한 별도 영구 작업공간으로 저장한다. 나중에 사용자가 원하는 프로젝트의 문서로 가져오기(import)한다.

C) AI 작업공간 결과는 정식 플랫폼 데이터로 저장하지 않고, 승인 시 Markdown/DOCX/XLSX 파일로만 다운로드한다.
